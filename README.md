### simpE is a simple way to benchmark small LLMs in the following areas:
- Instruction Following
- String Reversing
- Big Integer Addition
- String Rehearsal

## Install

```bash
git clone https://github.com/Dariton4000/simpE.git
```

```bash
cd simpE
```

```bash
uv sync
```

```bash
uv run simpe
```

```bash
uv run analyze
```
